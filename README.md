# Segredo Gelado - Sorvetes Artesanais

Back-end em Python para organizar pedidos de delivery, pagamentos, estoque e entregas.

Este repositório está recebendo em etapas a versão inicial do projeto. A documentação de instalação acompanha a publicação completa.

Tecnologias: Python, FastAPI, MySQL e autenticação JWT. Pagamentos, estornos e recebimentos das plataformas são simulados.
